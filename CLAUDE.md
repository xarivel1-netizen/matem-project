# CLAUDE.md — Matem.Project

## Контекст

Проект: веб-приложение для отслеживания плана изучения алгебры 10 класса
(учебник Мерзляк, базовый уровень). Приложение личное, но одновременно идёт
в портфолио как коммерческая работа — качество кода и UI на уровне продакшена.

В корне лежит `plan-source.md` — готовый план обучения. Это единственный
источник учебного контента. Прочитать целиком перед любой работой.

## Стек (не менять без согласия владельца)

Монорепо на **pnpm workspaces**: `apps/web`, `apps/server`, `packages/shared`

- **Клиент** (`apps/web`): React 18, TypeScript (strict), Vite, Tailwind CSS,
  Zustand, React Router, Framer Motion, KaTeX
- **Сервер** (`apps/server`): Node 20, Fastify, better-sqlite3, Drizzle ORM, zod
- **Общее** (`packages/shared`): общие типы и zod-схемы, импортируются обоими
  приложениями

## Правила работы

1. Работаем строго по этапам. Владелец даёт этап — делаешь только его и
   останавливаешься.
2. В конце каждого этапа пиши: что сделал, какие файлы создал/изменил, как это
   проверить руками, и жди «дальше».
3. **Структуру плана не выдумывай:** номера параграфов, темы, названия глав и
   распределение по дням — только из `plan-source.md`; чего там нет (номера §) —
   оставляй null и говори об этом.
   **Текст теории — можно и нужно генерировать** (владелец снял запрет 2026-08-12):
   пиши подробные корректные конспекты по темам в `theory-content.ts`. Условия
   задач по-прежнему не выдумываю без запроса.
4. TypeScript strict, никаких `any`. Валидация всех входных данных сервера
   через zod.
5. Комментарии в коде — на русском, только там, где логика неочевидна.
6. Никаких `localStorage` для учебных данных — источник правды это SQLite на
   сервере. `localStorage` можно только для темы оформления.
